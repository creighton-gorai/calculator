This project is your typical Calculator project using HTML, CSS and JavaScript.

Style: iPhone calculator app color scheme and layout for familiarity.

Base calculator current working functions:
Can calculate only positive integers.
Clicking AC will wipe the whole screen.
Clicking C will only delete a singular number/operator.
Duplicate operator symbols will not show if clicked multiple times.
Equals sign will not show up on calculator screen. Will still evaluate if possible.
If previous button clicked was another operator, it replaces it.
Clicking modulo(%), change sign(+/-) and decimal(.) will not work.

Future implementations:
Modulo operator
Decimals/floating point numbers
Negative numbers

Current Known bugs:
Large values will evaluate off screen.
Decimals can be evaluated, but will not be handled formally.
